## Own declaration order correction

A further six fresh native controls in `json-array-targets-review` exposed a
real defect in the first implementation. An earlier `declare global` file and
a later script file produce a native first cause in the script: the existing
binding owner merges scripts before global augmentations. Reconstructing own
declarations by captured file order chose the augmentation instead.
`vrun-e3e3dfb7-3673-4433-8134-549709d415de` reached the final public cause
assertion, passed the other six tests and failed this exact location difference.

The correction retains typed `(FileId, DeclId)` associations on canonical Store
symbols through the actual bind/merge operations. Native target-then-source
order moves with bidirectional merges and copies with directed merges; the
source keeps its separate identity. Physical canonical-module ID selection
preserves the caller's declaration order. The shared private own-declaration
operation now reads these associations, and declared/value/global acquisition
uses it with separate question-specific kind decisions. Lexical sites and
Index alias projections remain distinct. No new name-bearing search inventory
or global-only phase sort is introduced.

Final `vrun-51c73f61-f666-45e5-86ec-a8fbc1c1692b` passed seven public tests
with zero skips. It covers the augmentation/script difference, forward/reversed
script order, escaped decoded identity with the original raw cause span,
value-only alias eligibility and exact lowercase exclusion. This is bounded
first-cause evidence; arbitrary alias/module/merge histories remain part of the
full native binding/checker work.

The storage change adds a `SmallVec` per symbol and typed pairs of two existing
32-bit IDs, without duplicating declaration names, source spans or facts. A
single association stays inline; merged symbols can allocate, and one-way
merges copy associations as the native symbol copies declarations. Payload is
eight bytes per pair; that is not total retained heap or allocator capacity.
Acquiring a symbol's declarations now visits its own list instead of every
project declaration. Local parameter deduplication follows native
`AppendIfUnique` and can be quadratic in distinct parameters. Exact total
allocation/load effects have not been measured and do not close the resource
or representation gate. The coordinated full-library checkpoint recorded above
passed the private JSON parent/path delta and this public compatibility stage.
