# Native instantiation expressions

This owner serves `typeof f<T>` and runtime `f<T>` in the request-local evaluator. It follows pinned checker.go `checkExpressionWithTypeArguments` (10611), `getInstantiationExpressionType` (10634), and the existing `getObjectTypeInstantiation` owner (22209). The operating envelope is one captured project and one semantic request; no cross-request cache or new synchronization is needed.

Two ownership choices were considered: a separate instantiated-expression object representation/cache, or an actual anonymous object factory plus the existing object-instantiation and structured-member owners. The latter keeps one owner for outer parameter mapping, raw member installation, property identity and signature instantiation. Only the native node/operand-result cache is new.

The Source recipe retains the actual node, operand and nil-versus-written type argument list. Source checks of all written arguments precede operand checking. Each object completes signature filtering before argument checking and instantiation, calls before constructors. Ordinary constraint rejection preserves the original generic signature; an acquired failure remains a failure. Union constituents reset applicability facts; intersection constituents share them. The resulting applicability facts select the exact diagnostic type.

The factory allocates a fresh declarationless `SymbolFlagsNone` symbol named native `InternalSymbolNameInstantiationExpression`. Its object flags are Anonymous and InstantiationExpressionType. Raw member table nil-versus-present, existing property symbols and index identities are preserved through `setStructuredTypeMembers`. Synthetic `Type.symbol` headers now retain their established container flags explicitly; identity is not used to guess flags.

The actual expression node is retained in the existing anonymous association. Later instantiation filters outer parameters against that node and shares the existing object cache. The shared outer-parameter cache belongs to the actual declaration node, matching native type-node links, rather than to an individual instantiated object.

Native installs the expression result before diagnostic `TypeToString`. The shared `check_diagnostic_type_display` operation owns that traversal and its truncation/context policy. Reentry can observe the installed result; an ensuing display failure is retained in the product result cache. No omitted traversal may turn that failure into a healthy answer.

Proof inputs are `fixtures/types/native-instantiation-expressions`, the corresponding registered oracle harness, and `tests/type_instantiation_expressions.rs`. The matrix separates nil/written-empty arguments, defaults, too many arguments, nongeneric signatures, ordinary constraint rejection, calls/constructors, retained properties/indices, unions/intersections, scalar identities, enclosing type parameters, base constraints and consumed failures across strict, loose and exact-optional profiles. TypeQuery ancestry has its separate native/final matrix in `native-type-query-parameters` and `tests/type_query_parameters.rs`.

A substantive reporting prerequisite was found during review. `checkTypeArguments` calls direct `checkTypeRelatedToEx` in both modes; ordinary overload selection supplies Silent, while instantiation supplies Report. Report changes failed-cache replay, union target selection, weak-type return queries, signature candidate retries, and diagnostic display. The shared entry now preserves this distinction. Its Report branch is a located temporary Unsupported dependency, so the true native rejected-constraint expectation deliberately remains RED until the complete reporting Relater is implemented. It is not replaced with a silent comparison or blanket operand display. The next coherent owner is full reporting Relater, with actual error-chain state and shared native display operations; Mapped remains required after that prerequisite.

`getExpandedParameters` now has one signature owner, shared with diagnostic serialization. Raw rest type and full tuple argument acquisition precede labels; duplicate labels are renamed by the native collision loop; ordinary prefix rows retain their existing identities and synthesized rest rows keep nil declarations and native Optional/Rest check flags. `getParameterNameAtPosition` consumes the same `getTupleElementLabel` owner. Signature mapper observation reads the established instantiation/composite associations without acquiring return types.
