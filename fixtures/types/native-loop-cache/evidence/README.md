# Fresh loop and cache evidence

This archive records fresh TypeScript 7.0.2 requests against the copied tooling
and exact captured inputs. It is research evidence alongside the final product
tests, not an alternative type implementation or a claim that all flow/cache
families are delivered.

`fresh-api-answers.json` has 36 public oracle requests and 36 separate fresh
raw-symbol/location identity controls: 18 markers in strict and loose profiles.
All four pre-demand input diagnostic inventories are empty in the raw controls.
The executable suite `tools/type-loop-cache-oracle.test.mjs` passed two tests
with zero skips in `vrun-55ae3d8e-7c4d-4976-b9b2-de3c7c8d99d0`.
Its sourceHash observations equal the SHA-256 of `inputs/loops.ts`; the public
API output does not claim the compiler hook's full inputHashes field.

`fresh-hook-answers.json` has 16 separate cold same-checker sessions for eight
natural phase markers across both profiles. `fresh-hook-additions.json` has 16
further sessions against `addition-inputs`, and
`fresh-hook-unrelated-call.json` has two sessions against the later
`addition-v2-inputs` snapshot. Every hook row's inputHashes was checked against
the corresponding captured bytes, including inherited configuration. The two
addition versions are deliberate: appending the unrelated-call control did not
retroactively change the source of the earlier 16 requests.

The copied overlay only observes actual native callbacks/counters. It does not
seed native counters, change thresholds, force cache entries, or install an
assigned type before the selected query. `beforeSummary` preserves the actual
native loop identity, counters and accumulated diagnostic state before printing.
The noLib initial TS2318 global inventory is retained separately from new demand
observations. A non-error final root does not erase a consumed recovery child.

Natural witnesses include first-antecedent incompleteness and active reuse,
completed-loop installation, Normal expression-cache reset, restarted cache
pickup, and temporary resolved-call cache suppression. The demanded-Missing
addition observes an assigned ErrorType and new TS2304 before summary while the
final root remains the declared union. Restarted inferred-copy controls retain
the native TS7022 state. They are recovery/history controls, not healthy product
admission claims. The unrelated ambient-argument overload control observes call
cache suppression without substituting a transient narrowed argument identity.
`loopEmptyActive` was not naturally observed; exhaustive cache/reset and failure
unwind proof remains open.

`replay-before.json` and `replay-after.json` are equal SHA-256 maps for all four
shared JS modules and all four copied hook/oracle files. Each map entry also
matches its archived copy. `native-identity.json` records the native binary,
API package, pristine pinned Go commit/tag and whole native owner hashes;
`installed-api-inventory.json` freezes all 416 installed API files. Exact owner
anchors are included for source inspection. `provenance.json` hashes the final
archive artifacts, excluding itself to avoid a recursive manifest.

`historical-*.json` preserves earlier scratch observations as historical records.
The fresh replay supplies the exact provenance above; it does not invent missing
before/after input hashes for earlier histories. Copied scripts retain their
original `.cc/temp` layout and absolute imports. To replay them, restore that
layout using the captured files and verify the recorded tool/input hashes;
this directory is an evidence archive, not a portable standalone runner.
