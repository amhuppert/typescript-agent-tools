# Native generic Array dependency controls

These TypeScript 7.0.2 programs extend the genuine-target baseline. They do not
implement or admit native generic Array types. `tools/type-json-generics-oracle.test.mjs`
is a four-test registered baseline, GREEN
`vrun-b202cdec-24a1-4939-b6a9-0f322a21269c`, with no skips. Its identity matrix
uses eight cases in all eight strict-null/exact-optional/unchecked profiles: 48
fresh semantic requests have clean config/program/syntax/bind inventories, and
16 input-only controls explicitly assert Program TS5052.

The archived probe records 45 independent fresh native API requests. All four
input inventories precede each demand. The common demand is
`GetAliasedSymbol → GetTypeOfSymbol`, followed by Array target/argument/parameter
identities and summary. Separate named operations enumerate properties/indexes
or read one member, constraint or default TypeNode. There is no whole-file
semantic-diagnostics prelude. Default observations use
`GetTypeAtLocation(default TypeNode)`, not `GetDefaultFromTypeParameter`.

The missing constraint/default/member cases show raw native root and healthy
member answers remain established until those unrelated dependencies are
explicitly demanded. Their explicit missing annotation questions have true
native error flags. These facts do not admit a graph that consumes an invalid
child. The `unused-base` case is a raw root/inventory control only; false root
flags and an apparently empty inherited inventory do not prove healthy heritage
dependencies. Recovery and native guard provenance need their own owner proof.

The merged cases share one canonical T type identity across both declarations.
The later constraint is returned by `GetConstraintOfTypeParameter`; the later
default TypeNode is measured separately. The interface and class cases prove
actual property/index/method-return element substitution and `self: this` as the
exact instantiated Array identity. They do not prove general mappers, recursive
substitution, bases, defaults, readonly fallback or standard-library members.

The manifest freezes all 97 fixture `.ts`/`.json` inputs, the exact probe,
observations, registered test and its used semantic/vendor owners, the complete
installed API package file inventory, native binary and pinned checker source.
These are after-probe inspection hashes over a fixture tree kept stable during
capture, not a transactional native read inventory. The archived source retains
its original `.cc/temp` relative imports; copy it there to reproduce it using
the pinned API/native environment variables. Historical Array recovery
archives remain separate and unchanged.
