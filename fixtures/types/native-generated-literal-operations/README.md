# Native generated literal operations

Final-query probes consume the generated private key through concatenation,
casing, template capture, and conditional inference, returning ordinary scalar
answers. The source is independent of the raw contextual-output fixture.

Each strict/loose query compares TypeScript 7.0.2 API and same-checker hook
answers. Native captures live in expected-*.json after registered validation.
The product must not copy compiler process IDs: identityConcreteDigits is a
native reachability control whose product result must be
UnrepresentableIdentity. sameIdentity and identityNondigit distinguish equality
and a provable nondigit mismatch from that unavailable decimal comparison.

Coverage includes raw FE versus actual U+FFFD, all four intrinsic mappings,
unchanged raw bytes after a capitalized first rune, expansion mappings,
Final_Sigma context adjacent to an opaque decimal atom, surrogate pairs across
joined spans, lone/reversed sentinel bytes, and retained template placeholders.
